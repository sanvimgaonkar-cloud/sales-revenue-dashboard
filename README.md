# Sales Command Center V2

Run:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Required: Date, Revenue, Product.
Optional: Units/Quantity, Category, Region, Channel.

Features:
- Excel/CSV and SQLAlchemy database import
- KPI cards
- Monthly/quarterly/daily revenue trends
- Revenue mix
- Top-product leaderboard
- Date/category/region/channel slicers
- Drill-down analysis
- Filtered CSV export
